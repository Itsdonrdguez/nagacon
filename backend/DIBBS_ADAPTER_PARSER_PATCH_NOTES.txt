DIBBS adapter parser patch

Changed file:
- backend/app/services/dibbs_adapter.py

What this captures:
- solicitation number
- title
- FSC
- NSN / dibbs_value
- posted_at
- due_at
- detail/package link

How it works:
- requests the DIBBS FSC search page
- tries structured table parsing first
- falls back to link-based parsing if table detection fails
- returns normalized row dicts plus diagnostics

Retest:
1) restart backend
   uvicorn app.main:app --reload

2) run DIBBS scrape
   Invoke-RestMethod -Method Post "http://127.0.0.1:8000/api/scrapers/dibbs/run" -ContentType "application/json" -Body '{"max_pages":1,"fsc":"6520","limit":10}' | ConvertTo-Json -Depth 10

3) inspect latest opportunities
   Invoke-RestMethod "http://127.0.0.1:8000/api/opportunities?limit=10&offset=0" | ConvertTo-Json -Depth 10
