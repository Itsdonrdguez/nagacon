# Archive Notes

This folder is the intended home for legacy patch notes, one-off debugging writeups, and historical implementation memos that are still useful for reference but should not live in the repo root long term.

Suggested move candidates from `backend/` over time:

- `README_PATCH.txt`
- `README_FIX.txt`
- `PATCH_NOTES.txt`
- `DIBBS_*_PATCH_NOTES.txt`
- `README_DIBBS_*`
- `PHASE*_README.txt`

Guideline:

- keep active engineering docs in `docs/`
- move historical/debugging notes into `docs/archive/`
- avoid adding new patch-note files at the repo root
