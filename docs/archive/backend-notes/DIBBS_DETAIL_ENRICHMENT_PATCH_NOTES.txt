DIBBS detail enrichment patch

Files:
- backend/app/services/dibbs/detail_enrichment.py
- backend/app/api/dibbs_enrich.py

What it does:
- enriches existing DIBBS opportunities using their direct RFQ URL
- extracts:
  - NSN
  - FSC
  - part numbers
  - manufacturer/brand clues
  - approved-source-like tokens
  - PDF / attachment links
- stores parsed data in raw_payload["dibbs_detail"]
- backfills description and fsc_code when available

How to wire:
1) Put the files in the paths above
2) In app/main.py add:
   from app.api.dibbs_enrich import router as dibbs_enrich_router
   app.include_router(dibbs_enrich_router)

Retest:
uvicorn app.main:app --reload

Invoke-RestMethod -Method Post "http://127.0.0.1:8000/api/dibbs/enrich" -ContentType "application/json" -Body '{"limit":5,"source":"DIBBS"}' | ConvertTo-Json -Depth 10

Then inspect:
Invoke-RestMethod "http://127.0.0.1:8000/api/opportunities/49" | ConvertTo-Json -Depth 20
